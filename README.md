### 1. Тема и концепция

#### Название: M-DROP  
#### Краткое описание:  
 **M-DROP** - это специализированный интернет-магазин музыкального мерча, предлагающий ассортимент от культовых рок-исполнителей до всемирно известных Pop и K-pop групп. Платформа помогает фанатам находить эксклюзивные товары (альбомы, одежда, аксессуары, плакаты и т.д.) в удобном цифровом формате. Проект обеспечивает быстрый и удаленный доступ к качественной атрибутике любимых артистов.  

#### Целевая аудитория:  
 - Меломаны и фанаты музыкальных групп(от подростков до взрослых людей), которые носят или коллекционируют мерч любимых групп/исполнителей.  
 - Покупатели подарков - люди, которые хотят найти подарок для фанатов музыки.  
 - Люди следящие за музыкальными трендами, которые предпочитают быстрый и удобный онлайн-шоппинг.  
 - Возростная категория: от 16 до 50 лет, как женщины, так и мужчины.    
Ключевой функционал:  
 - Система аутентификации (регистрация, вход, восстановление пароля) для доступа к личному кабинету.  
 - Каталог товаров  с фильтрацие по исполнителю, типу товара(альбомы, футболки и т.п.) и цене.  
 - Система поиска товаров.  
 - Детальная страница товара с картинкой, описанием и ценой.  
 - Возможность управления корзиной(добавление и редактирования списка покупок).  
 - Возможность редактрования личного кабинета.  
 - Административная панель для управления товарами(доступна только владельцу и админам магазина).

### 2. Структура приложения (9 разделов)  
#### Список разделов:  
 1) Главная(/) - публичная.  
 2) Аутентификация(/auth/*) - публичная.

 4) Страница товара(/catalog/:id) - публичная, динамическая.

 6) Корзина(/cart) - приватная.

### 3. Технологический стек    
 #### Frontened:  
  - Фреймворк: Vue 3  
  Выбран за высокую производительность, гибкую систему реактивности и удобную структуру кода через Composition API. Это позволяет эффективно создавать динамические компоненты мерч-шопа, такие как интерактивные карточки товаров и обновляемая в реальном времени корзина.  
  - Роутер: Vue Router   
  Выбран за высокую производительность, гибкую систему реактивности и удобную структуру кода через Composition API. Это позволяет эффективно создавать динамические компоненты мерч-шопа, такие как интерактивные карточки товаров и обновляемая в реальном времени корзина.    
  - State-менеджмент: Pinia             
  Современное и легковесное решение для управления глобальным состоянием приложения. Оно упрощает работу с данными (пользователь, корзина), обеспечивая простоту, поддержку Composition API и TypeScript.
            
 #### Backend:  
 - **Среда разработки**: *Node.js*  
 Позволяет использовать JavaScript на стороне сервера, упрощает передачу данных между фронтендом и бэкендом.  
 - **Фреймворк**: *Express.js*  
 Гибкий фреймворк для Node.js. Он идеально подходит для создания REST API, обработки маршрутов (эндпоинтов) и интеграции промежуточного ПО (middleware) для проверки авторизации пользователей.  
 - **База данных**: *Supabase (PostgreSQL)*  
   Supabase предоставляет мощную базу данных PostgreSQL. Это гарантирует строгую структуру данных и надежные связи между таблицами (например, связь пользователя и его заказов).  
    
 #### Инфраструктура API:     
 - **Хостинг Frontend**: *GitHub Pages*    
   Идеально подходит для размещения собранного Vue 3 приложения. После выполнения команды npm run build, проект превращается в набор статических файлов, которые GitHub Pages бесплатно и надежно раздает пользователям.   
 - **Хостинг Backend**: *localhost*

### 4. Визуальное проектирование интерфейса

#### Страница 1: Главная(/)
Тип доступа: публичный.  
Основные блоки:  
1) Шапка: логотип M-DROP, меню (Каталог, Поиск), иконка корзины, кнопка «Войти» или аватар пользователя(если авторизован).  
2) Блок: рекламный баннер с кнопкой «Смотреть новинки».  
3) Секция «Популярный мерч»: сетка из 6 карточек товаров (данные из GET /api/products?popular=true).   
4) Футер: ссылки на соцсети, контакты.  
Динамический контент: блок 3 (список популярных товаров загружается с API).

#### Страница 2: Аутентификация (/auth/*)  
Тип доступа: публичный.  
Основные блоки:   
1) Шапка: логотип "M-DROP".  
2) Форма входа/регистрации: поля для входа(Email, Пароль), поля для регистрации(Email, Пароль, Подтверждение пароля), кнопки «Войти» и «Зарегистрироваться», ссылка «Восстановить пароль».  
3) Валидация: вывод ошибок при некорректном вводе данных.  
Динамический контент: статус авторизации (данные из POST /api/auth/login или register).  

#### Страница 3: Каталог(/catalog)  
Тип доступа: публичный.  
Основные блоки:  
1) Шапка: логотип M-DROP, навигация (Поиск), иконка корзины, аватар пользователя.  
2) Боковая панель с фильтрами и сортировкой:
 -Фильтр по исполнителю (список чекбоксов: Metallica, Lana Del Rey, BTS и т.д.)  
 -Фильтр по категории (альбомы, футболки, аксессуары, плакаты и т.д.)   
 -Фильтр по цене (поля "от" и "до" с кнопкой "Применить")   
 -Кнопка "Сбросить все фильтры"   
 -Сортировка (выпадающий список: по популярности, по возрастанию цены, по убыванию цены, по новизне).    
3) Сетка товаров: список карточек (картинка товара, название, цена, кнопка «В корзину»).    
4) Футер: ссылки на соцсети, контакты.  
Динамический контент: блок 3(все товары в основной области обновляются при применении фильтров и сортировке).  

#### Страница 4: Страница товара(/catalog/:id)  
Тип доступа: публичный.  
Основные блоки:  
1) Шапка: логотип M-DROP, иконка корзины, аватар пользователя.  
2) Блок товара: большое изображение товара, детальное описание(производитель, артист/группа, материал, качество и т.п.), цена, информация о наличии(есть в наличии/ нет в наличии).  
3) Выбор параметров: выбор размера или версии альбома.      
4) Действие: кнопка «Добавить в корзину».
5) Футер: ссылки на соцсети, контакты.   
Динамический контент: блок 2 (вся информация загружается по ID из эндпоинта GET /api/products/:id).  

#### Страница 5: Поиск(/search)  
Тип доступа: публичный.  
Основные блоки:  
1) Шапка: логотип M-DROP, строка поиска(в ней отображается введенный запрос), иконка корзины, аватар пользователя.    
2) Заголовок: "Результаты поиска по запросу: '[текст запроса]'"  
3) Состояние с данными:  
 -Сетка найденных товаров (такой же формат карточек, как в каталоге)  
 -Если товаров нет: заглушка "По вашему запросу ничего не найдено" + кнопка "Перейти в каталог"
4) Футер: ссылки на соцсети, контакты.    
Динамический контент:блок 3(результаты поиска подгружаются из API на основе введенной строки).

#### Страница 6: Корзина(/cart)  
Тип доступа: приватный.  
Основные блоки:  
1) Шапка: логотип M-DROP, аватар пользователя.  
2) Список сохраненных товаров: перечень добавленных товаров с возможностью изменения их количества или удаления.
3) Блок "Итого": общее количество товаров, общая сумма товоров в корзине
4) Кнопка "Перейти к оформлению" (активна, если корзина не пуста, ведет на /checkout)   
5) Футер: ссылки на соцсети, контакты.  
Динамический контент: блок 3(данные берутся из модели User (поле cart)).

#### Страница 7: Оформление заказа(/checkout)  
Тип доступа: приватный.  
Основные блоки:  
1) Шапка: логотип M-DROP, аватар пользователя.  
2) Заголовок: "Оформление заказа"
3) Блок: краткая информация об товаре 
4) Форма данных: контактные данные(автоматически подставляются из профиля), ввод адреса(гоород, улица, дом, квартира) доставки и выбор способа оплаты(картой онлайн/при получении).  
5) Итоговый расчет: финальная стоимость с учетом доставки.  
6) Кнопка "Подтвердить заказ".       
7) Футер: ссылки на соцсети, контакты.    
Динамический контент: блок 3 и 4 (данные профиля (для автозаполнения), состав заказа).  

#### Страница 8: Личный кабинет(/profile)  
Тип доступа: приватный.  
Основные блоки:
1) Шапка: логотип M-DROP, иконка корзины.  
2) Заголовок: "Личный кабинет".  
3) Блок данных: имя, email, номер телефона, фотография пользователя.
4) Кнопка редактирования: для изменения данных.
5) Кнопка выхода из профиля.  
6) Футер: ссылки на соцсети, контакты.  
Динамический контент: блок 3 (вся основная информация (имя, телефон, почта, аватар) подтягивается из базы данных через API (модель User).).

#### Страница 9: Админ-панель(/admin)  
Тип доступа: приватный(Admin).  
Основные блоки:
1) Шапка: логотип "M-DROP Admin", индикатор роли "Admin".    
2) Таблица товаров: ID, название, исполнитель, категория, цена, наличие.
3) Кнопка "Добавить товар" (открывает форму с полями из модели Product)       
4) Для каждого товара: кнопки "Редактировать" и "Удалить".    
Динамический контент: блок 2 (список всех товаров с БД).

### 5. Схема данных и API

#### Основные модели данных:  
 Модель *User*:
| Поле     | Тип данных     | Описание                                 | 
| -        | -              | -                                        | 
| id       | UUID / число   | Уникальный ID                            |
| role     | Строка         | Роль для доступа к админ-панеле          | 
| email    | Строка         | Адрес почты                              | 
| password | Строка         | Хеш пароля                               | 
| name     | Строка         | Имя пользователя                         | 
| phone    | Строка         | Номер телефона                           | 
| avatar   | Строка (URL)   | Ссылка на фото профиля                   | 
| cart     | Массив (ID)    | Список ID товаров, добавленных в корзину | 

 Модель *Product*:
| Поле      | Тип данных     | Описание                      | 
| -         | -              | -                             | 
| id        | UUID / число   | Уникальный ID товара          |
| name      | Строка         | Название товара               | 
| artist    | Строка         | Группа/исполнитель            | 
| price     | Число          | Цена товара                   | 
| category  | Строка         | Категория(альбом,одежда и тд) | 
| image     | Строка (URL)   | Ссылка на фото товара         | 
| stock     | Число          | Количество в наличии          | 

*Ключевые эндпоинты API*:  
| Метод    | Эндпоинт           | Описание                                       | 
| -        | -                  | -                                              | 
| POST     | /api/auth/register | Регистрация                                    |
| POST     | /api/auth/login    | Вход                                           | 
| GET      | /api/products      | Получение списка товаров                       | 
| GET      | /api/products/:id  | Получение деталей конкретного товара по ID     | 
| POST     | /api/orders        | Создание заказа (связь пользователя и товаров) |
